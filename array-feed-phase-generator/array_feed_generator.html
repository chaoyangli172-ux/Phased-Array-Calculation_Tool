Formulas and Assumptions (Click to expand)
The coordinate system is consistent with the HFSS top view: x downward, y rightward, z pointing into the screen. The physical coordinates of the antenna elements are denoted as (i, j), where i is the index along the x-axis (downward) and j is the index along the y-axis (rightward), both starting from 0. The top-left element (i=0, j=0) is always the reference element — the dx and dy coefficients for this element are strictly 0 for all three grid types. The local indices within each 2×2 subarray are mapped as (i%2,j%2) = (0,0)→L0, (1,0)→L1, (1,1)→L2, (0,1)→L3 (consistent with the 90/0/−90/−180 sequential rotation order in the reference file).
  • Rectangular Grid: X = i, Y = j.
  • Triangular Grid A: X = 2·i + (j mod 2), Y = j (Columns 2/4/6... are collectively offset by +0.5 spacing along the x-axis). Verified line-by-line against all 32 ports in sc44tri.csv with zero error.
  • Triangular Grid B (Mirrored): X = 2·i − (j mod 2), Y = j (The same columns are instead offset by -0.5 spacing along the x-axis, with the reference element remaining 0). Verified line-by-line against all 32 ports in sc44single.csv with zero error.
Phase per port = base − dx·X − dy·Y, where base takes a value from the sequential rotation sequence either [0,−90,−180,−270] or [0,90,180,270] (indexed by the subarray local index L0..L3). For dual-port excitation, Port A = Port B base ± quadrature phase difference (use + for rotation A and - for rotation B, perfectly matching sc44.csv / sc44tri.csv); for single-port excitation, the excited port directly uses the Port B formula (perfectly matching sc44single.csv).

In the previous version, the mirror formula for Triangular Grid B was reversed (using (j+1) mod 2), causing the reference element to be non-zero and resulting in an overall dx coefficient difference of 2×dx compared to sc44single.csv — as you pointed out, this is fundamentally because when fixing the top-left as the reference element for the two triangular grids, the first element of columns 2/4/6... takes +dx and −dx respectively. This has now been corrected to the X = 2·i ± (j mod 2) format above, with both directions strictly zeroed at the reference element.
